# UX/UI Design Document: Лендинг КЭМ-26 "ГРАВИТАЦИЯ"

## Executive Summary

**Тип проекта:** Лендинг для сбора лидов (продажа билетов на конференцию)
**Целевая аудитория:** Владельцы медицинских клиник, врачи-предприниматели, руководители медбизнеса
**Основной источник трафика:** Telegram канал @iskandarova_olesya
**Ключевая конверсионная цель:** Оставить телефон для записи на конференцию
**Дата создания:** 02.02.2026

---

## 1. User Research & Context

### 1.1 Целевая аудитория

| Сегмент | Характеристика | Pain Points | Мотивация |
|---------|----------------|-------------|-----------|
| **Владельцы клиник** | 35-55 лет, доход 200K+/мес | Нехватка знаний в маркетинге/IT | Рост бизнеса, масштабирование |
| **Врачи-предприниматели** | 30-45 лет, открывают свою практику | Финансовая грамотность, управление | Успешный запуск бизнеса |
| **Руководители медбизнеса** | 40-60 лет, опытные управленцы | Адаптация к digital, новым трендам | Конкурентоспособность, лидерство |

### 1.2 Пользовательский путь (User Journey)

```
Telegram канал → Пост с анонсом → Клик по ссылке → Лендинг (мобильный)
    ↓
Скроллинг: Hero → О конференции → Программа → Спикеры → Отзывы
    ↓
CTA: Оставить телефон → Форма (только телефон) → Confirmation
    ↓
Обработка агентом → Передача в КЭМ → Продажа билета
```

### 1.3 Конкурентный анализ

**Паттерны успешных event-лендингов:**
- Яркий hero с датой/местом в первом экране
- Таймер обратного отсчета (urgency)
- Фото спикеров с именами (social proof)
- Минимум текста, максимум визуала
- Sticky CTA кнопка при скролле

## 4. Interaction Design

### 4.1 Микроанимации

| Элемент | Триггер | Анимация | Длительность |
|---------|---------|----------|--------------|
| CTA кнопка | Hover | Подъем + тень | 300ms |
| Карточки спикеров | Hover | Увеличение + тень | 300ms |
| Форма | Focus | Свечение border | 200ms |
| Sticky CTA | Scroll down >300px | Slide up from bottom | 400ms ease-out |
| Accordion | Click | Expand/collapse | 350ms cubic-bezier |
| Countdown | Каждую секунду | Flip numbers | 600ms |

### 4.2 Scroll Behavior

```
Плавный скролл к якорям (smooth scroll):
Клик по CTA → плавный скролл к форме (800ms)

Parallax (легкий):
Hero фон — скорость 0.5x от скролла

Fade-in на секциях:
Элементы появляются при скролле (Intersection Observer)
Offset: 100px от viewport
Transition: opacity 600ms, transform 600ms
```

### 4.3 Responsive Breakpoints

## 5. Accessibility (WCAG 2.1 AA)

### 5.1 Обязательные требования

| Критерий | Реализация |
|----------|------------|
| **Контраст** | Текст: 4.5:1, крупный текст (24px+): 3:1 |
| **Фокус** | Видимый outline на всех интерактивных элементах |
| **Клавиатура** | Tab навигация, Enter для кнопок |
| **Alt текст** | Все изображения с описанием |
| **Форма** | Label для всех полей, aria-required |
| **Семантика** | H1-H6 иерархия, section, article, nav |

## 6. Performance Optimization

### 6.1 Метрики целевые

| Метрика | Target | Обоснование |
|---------|--------|-------------|
| **LCP** | <2.5s | Быстрая загрузка Hero |
| **FID** | <100ms | Мгновенная реакция на клик |
| **CLS** | <0.1 | Стабильность при загрузке |
| **TTI** | <3.5s | Быстрая интерактивность |
| **Page Size** | <500KB | Мобильный трафик |

### 6.2 Оптимизация изображений

```
Фото спикеров: 300x300px, WebP, качество 75%, ~20KB
Фото Олеси: 400x400px, WebP, качество 80%, ~30KB
Hero фон: 1920x1080px, WebP, качество 70%, ~80KB
  (для mobile: 800x600px, ~30KB)

Lazy loading для изображений вне viewport:
<img loading="lazy" src="..." alt="...">
```

### 6.3 Критический CSS (Above-the-fold)

```
Inline CSS в <head> для Hero секции:
- Типографика H1
- CTA кнопка стили
- Hero фон
- Layout (flexbox/grid)

Остальной CSS — defer load
```

- [ ] Page size <500KB
